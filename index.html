Bootcamp Mini Project
This website (yes, this one) brings together many of the themes and features explored so far in the Coders Guild Bootcamp and previous learning experience. It is built using HTML5, CSS3 (including Flexbox and Bootstrap), and JavaScript. The Bootstrap framework has been used to provide responsive layout and components.
Navigation bar

A navigation top bar that remains sticky at the top of the viewport as the user scrolls down the page. It contains a dropdown menu for quick navigation to different sections of the page and leads into the main hero image.

Animations

The main hero image starts hidden with overlaid css animations to display an introductory text animation. Each a careful mix of opacity, position, and hidden elements timed to create the overall display.

Work Samples Cards

Bootstrap cards illustrate pieces of work completed, with each card containing an image, title, and brief description. Each card zooms on hover and initially fades into view as the user scrolls down the page. Clicking on a card opens a modal with more information about that project. The cards are responsive and adjust their layout based on the screen size. A static backdrop adds interest to the page.

Source code available on GitHub: https://github.com/michael-dalton-home/mini-project
Hosted site: https://all-about-michael-dalton.netlify.app
Mock Travis Cars Project
A personal project to reinvent a real world website supporting a real world business - Travis Cars. Built using HTML5, CSS3 (including Flexbox and Bootstrap), and JavaScript. With Bootstrap framework supporting much of the responsive layout and components. The site is not functional but is a mock up to demonstrate layout and design skills. Test data is used in lieu of the absence of a backend database.
Hero Title Overlay

Introducing the website is an overlay to the attractive hero image, comprising site title and description explaining the site purpose. The semi opaque background the the titles fades in quickly followed by text description. Subtle wide expansion on the title text increases presence and is slightly brighter to encourage user focus.

Attractions Section

Following the titles and hero is a section illustrating what services the client company provide and why they are a good choice. Implemented as a series of rows each containing image and text, side by side using columns with Bootstrap managing the layout and responsive design. Care taken to order the image and text appropriately for different screen sizes to maintain user experience.

Footer Section

Footer contains contact details, company logo, and copyright. Contact info is real life, and each headed by an appropriate icon to enhance visual appeal and understanding. The company logo reaffirms brand identity while the copyright statement reaffirms that all details relating to the business are in fact their property.

Inventory Cards

Clicking through to the inventory reveals a new page listing available (and sold) cars. Each car has it's own Bootstrap card containing image, title, brief description, and price. Cards are arranged in a containerised responsive layout. Hovering over a card slightly enlarges it to indicate interactivity, and click through invokes a static modal which is populated with more detailed information about the selected car. The cards are created dynamically using javascript whereas the modal is a static Bootstrap component which is populated on invocation with appropriate test data.

Source code available on GitHub: https://github.com/michael-dalton-home/travis-cars
My hosted site: https://mock-travis-cars.netlify.app/
Real world business site: https://www.traviscars.co.uk/
Mock Garden Room Project
A Coders Guild project focused on recreating a real world business website - Garden Rooms. Built using HTML5, CSS3 (including Flexbox and Bootstrap), and JavaScript. With Bootstrap framework supporting much of the responsive layout and components.
Hero Title Overlay

Introducing the website is an overlay to the hero image, comprising site title and description explaining the site purpose. The semi opaque background the the titles fades in quickly followed by text description.

Navigation bar - Big View

On a large layout, the navigation bar spans the top of the viewport and remains sticky as the user scrolls down the page.

Navigation bar - Small View

On a smaller screen layout, the navigation bar collapses into a hamburger menu to save space. Clicking the hamburger reveals the full menu options.

Carousel

Below the hero image is a Bootstrap carousel component which cycles automatically through images of different garden rooms. Overlaid on each image is desdriptive text to inform the user what they are seeing.

SVG Decoration

Breaking up delineation between carousel and cards is a decorative SVG graphic. This helps give the page a more fluid look.

Cards

Feeding the imagination of the user, is a sequence of Bootstrap cards illustrating different garden room styles. Each card contains an image, title, and brief description. Hovering over a card slightly enlarges it to indicate potential interactivity. The same SVG surrounds this section. Y-reversed on the bottom of the section.

Accordian

The FAQ section is implemented as a Bootstrap accordian component. This allows the user to expand and collapse questions of interest, while keeping the overall section compact and easy to navigate.

Source code available on GitHub: https://github.com/michael-dalton-home/garden-room
My hosted site: https://mock-garden-rooms.netlify.app/
Real world business site: https://gardenroomsanctuary.co.uk/
